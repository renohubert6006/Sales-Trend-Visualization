# Graphs and Charts

This folder contains the visualizations generated during the Sales Trend
Visualization project.

## Visualizations

### 1. Monthly Sales Trend
Shows how total sales changed month by month from 2011 to 2014.

### 2. Sales by Category
Compares sales performance across different product categories.

### 3. Sales Prediction
Shows the actual monthly sales values together with the Linear Regression
trend used for prediction.

These charts were created using Python visualization libraries and are
included as supporting outputs for the project analysis.
