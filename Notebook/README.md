# Notebook / Code

This folder contains the Python notebook used to develop the Sales Trend
Visualization project.

## Notebook

- `sales_visualization.ipynb`

The notebook contains the complete project workflow, including:

1. Data loading
2. Data inspection
3. Data cleaning
4. Data preprocessing
5. Sales visualization
6. Sales analysis
7. Linear Regression prediction
8. Results and interpretation

The notebook was developed using Python in Google Colab.
