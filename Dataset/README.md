# Dataset

This folder contains the datasets used for the Sales Trend Visualization project.

## Files

- `SuperStoreOrders.csv` - Original raw sales dataset.
- `cleaned_sales_data.csv` - Cleaned and processed dataset used for analysis.

## Dataset Information

- Records: 51,290
- Original attributes: 21
- Data type: Sales transaction data
- Time period: 2011–2014

The dataset contains information including order dates, shipping details,
customers, segments, countries, regions, products, sales, quantity,
discount, profit, shipping cost, and order priority.

The original dataset was cleaned and prepared using Python and Pandas
before performing visualization, analysis, and prediction.
