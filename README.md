# Sales Trend Visualization

## Project Overview

The Sales Trend Visualization project analyzes historical sales data to identify
important sales trends, patterns, and business insights. The project includes
data cleaning, visualization, analysis, prediction modeling, and dashboard
creation using Python.

## Dataset

The dataset contains 51,290 sales records and 21 original attributes covering
sales transactions from 2011 to 2014.

## Objectives

- Data Cleaning and Preprocessing
- Sales Trend Analysis
- Data Visualization
- Sales Prediction
- Interactive Dashboard Creation
- Business Insights Generation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Plotly
- Google Colab

## Project Workflow

1. Data Collection
2. Data Inspection
3. Data Cleaning
4. Data Preprocessing
5. Data Visualization
6. Sales Analysis
7. Prediction using Linear Regression
8. Interactive Dashboard Creation
9. Results and Conclusion

## Visualizations

The project includes the following visualizations:

- Monthly Sales Trend
- Sales by Category
- Sales Prediction using Linear Regression
- Sales by Region
- Top 10 Products

## Prediction Model

A Linear Regression model was developed using historical monthly sales data.
The model was used to analyze the overall sales trend and generate future
sales predictions.

## Dashboard

An interactive dashboard was created using Plotly to display key performance
indicators and important sales visualizations in a single interface.

The dashboard includes:

- Total Sales
- Total Profit
- Total Quantity
- Average Discount
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Top 10 Products
